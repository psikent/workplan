## Background

生产启用前必须用规格中的标准数据集证明正确性、性能和回退准备，而不是依赖少量单元测试或人工抽样。

## Work

1. 建立可重复生成十万条工作计划、50 个自定义字段及边界分布的性能数据工具；不得包含生产数据或真实凭据。
2. 运行并记录查询首/后续页、工作台、十并发只读和十万行 XLS 的 p50/p95/p99、内存、查询计划和环境信息。
3. 补齐自动化矩阵：全部字段/方向/缺失值、稳定兜底、半开边界、游标、并发变化、准确总数、旧 offset、导出、墓碑、旧备份和自定义字段保护。
4. 完成真实浏览器矩阵：Administrator/Editor/Viewer，桌面/窄屏，鼠标/纯键盘，URL/偏好/账户切换/归档降级/加载失败，表格/甘特/XLS 一致。
5. 验证生产配置下的迁移预检、数据库备份、回退开关、墓碑统计和重新加入中性 `sort_order` 的前向修复脚本；不得执行最终删列。
6. 运行 Web 与全仓 typecheck/test，记录命令、测试数量、浏览器观察和所有已知限制。
7. 任何预算失败都回到对应实现票据修复；不得通过放宽预算或弱化断言完成本票。

## Acceptance

- 所有正确性、浏览器和回归矩阵通过。
- 查询、并发、工作台、XLS 和加载反馈达到规格预算。
- 回退和备份演练可重复，发布候选不包含最终删列迁移。
- 本票 `## Comments` 有完整、可核对的验收证据，可交给生产观察票据使用。
