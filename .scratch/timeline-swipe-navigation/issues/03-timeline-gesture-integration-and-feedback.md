# 03 — 时间轴手势接线、滚动交接与边缘反馈

Type: task
Status: resolved
Blocked by: 01, 02
Spec: ../spec.md
Scope: apps/web/src/components/GanttTimeline.tsx、apps/web/src/pages/WorkPlansPage.tsx、apps/web/src/styles.css、对应渲染与页面测试

## 背景

规格 R2–R7。票据 01 提供统一范围导航，票据 02 提供纯手势状态机；本票将它们接入真实 Frappe Gantt DOM，并保护横向/纵向滚动、甘特条排期、提醒、双击新建和全屏等现有行为。

## 改动清单

1. 在 `GanttTimeline` 与 `WorkPlansPage` 之间增加最窄的范围导航回调/状态 seam；普通模式、甘特全屏、空数据、加载及失败网格都能开始有效手势。
2. 仅允许从日期表头空白或日期网格背景开始；以事件委托排除甘特条、手柄、提醒铃铛、按钮、工具栏、tooltip/popover 和其他交互目标。抽屉、对话框或浮层打开时不向时间轴提供可用手势入口。
3. 手势开始时读取 `.gantt-container` 的真实 `scrollLeft`、`scrollWidth` 和 `clientWidth`；有范围内余量时保留原生横向滚动，只有从对应边界向外的新手势交给状态机。纵向动作保持原生滚动。
4. 不在方向未确定前阻止默认行为；锁定为水平切换候选后才捕获指针并抑制兼容点击，确保失败/取消动作不触发日期双击、甘特条打开或其他点击副作用。
5. 在时间轴边缘渲染不拦截事件的方向箭头与上一/下一周/月文案，按状态机进度调整强度；只使用主题 token，并为 `prefers-reduced-motion` 提供静态反馈。
6. 松手成立后调用票据 01 的统一导航入口；Gantt 重建完成后，前进恢复到横向左端、后退恢复到横向右端，按钮和手势一致。纵向回到顶部并保持列表/甘特同步。
7. 加载和失败覆盖层不得阻断后续有效范围手势；300ms 冷却结束后可继续逐步导航，但迟到查询结果不得恢复旧 DOM。

## 验收

- 渲染测试证明有效背景能导航，交互目标、浮层、浏览器边缘保留区和非触摸输入不能导航。
- 月/极窄周视图先范围内滚动，只有从边界开始的新外滑才换范围；无横向余量时左右均可换。
- 前后范围横向落点、纵向归顶、普通/全屏、空态、加载、失败和只读账户符合规格。
- 甘特条点击/拖动/拉伸、提醒、网格双击新建、悬停与纵向同步测试无回归。

## Comments

- 不引入整张画布跟手轮播、触控板导航、鼠标拖动导航或新的持久化偏好。
