# 02 — 单指边界滑动判定状态机

Type: task
Status: resolved
Blocked by: none
Spec: ../spec.md
Scope: apps/web/src/components/GanttTimeline.tsx（或新增同层纯 helper）、对应单元测试

## 背景

规格 R2–R4。时间轴同时承载范围内横向滚动、纵向滚动、甘特条交互和日期网格操作；应先用无 DOM 或最小 DOM 依赖的状态机固定单指、边界、方向、阈值、取消和冷却语义，再由票据 03 接入真实时间轴。

## 改动清单

1. 实现可独立测试的触摸滑动判定：只接受 `pointerType === "touch"` 的单指序列，记录起点、可见时间轴宽度、起始横向边界和浏览器边缘保留区。
2. 自适应阈值为 `clamp(可见宽度 × 15%, 48px, 80px)`；水平位移须至少为垂直位移的 1.5 倍。左边界右滑候选上一范围，右边界左滑候选下一范围；无滚动余量时两向均可候选。
3. 只有手势开始时已经处于对应边界才可候选；从范围内部开始并在途中到达边界的动作保持普通滚动，不在同一次手势中翻页。
4. 松手时提交；松手前反向回到阈值以内取消。一次最多返回一个 `previous` 或 `next` 结果。
5. 第二触点、纵向意图、`pointercancel`、窗口失焦或捕获丢失立即取消；非触摸 Pointer Event 始终无结果。
6. 输出适合视觉层消费的候选方向与 0–1 进度；成功后启动约 300ms 冷却，取消或失败手势不启动冷却。

## 验收

- 纯判定测试覆盖 48/80px 钳制、15% 中间值、1.5 倍边界、左右方向、反向撤销、松手提交和一次一步。
- 覆盖左/右/双边界、范围内部起步、24px 浏览器边缘保留、第二触点及全部取消路径。
- 覆盖鼠标、触控板对应的 wheel/非 touch pointer、触控笔均不会返回范围导航结果。
- 状态机不写页面状态、不调用 API，也不直接依赖 Frappe Gantt 内部对象。
