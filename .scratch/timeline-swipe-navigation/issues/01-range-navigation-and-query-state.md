# 01 — 日历安全的范围导航与查询状态

Type: task
Status: ready-for-agent
Blocked by: none
Spec: ../spec.md
Scope: apps/web/src/pages/WorkPlansPage.tsx、apps/web/src/lib/format.ts（或同层日期 helper）、对应单元与页面测试

## 背景

规格 R1、R5、R6。现有 `shiftRange` 在月视图直接执行 `Date.setMonth(±1)`，月底可能溢出并跳过目标月份；范围变化期间 TanStack Query 的 placeholder 数据也不能被当成目标范围数据绘制。本票先建立按钮与手势共用的正确导航和页面状态契约。

## 改动清单

1. 提供可测试的日历安全范围移动逻辑：周视图严格前后移动 7 个本地日历日；月视图严格进入相邻自然月，覆盖月末、二月、闰年和跨年，不依赖会溢出的原日号。
2. 让“上一时间范围”“下一时间范围”按钮使用该逻辑，并为后续手势接线暴露同一个页面级导航入口；导航结果须携带前进/后退方向，以支持前进落左端、后退落右端。
3. 每次范围导航保留视图、搜索、筛选、显式排序、全屏、列表展开、列宽和显示属性；重置游标分页到第一页，并把工作内容列表及甘特纵向滚动恢复到顶部。
4. 范围提交后立即更新标题和目标日期网格；`isPlaceholderData` 期间不得把旧范围 Work Plan 传给列表或 `GanttTimeline`，改为目标网格上的明确加载状态。
5. 加载失败时保持目标范围，显示失败与重试入口；仍允许按钮或后续手势导航离开。连续导航时只接纳最终当前范围的数据，迟到响应不得覆盖。
6. 不改变“今天”、周/月 Tab、筛选条件、路由初始参数、API、权限或持久化行为。

## 验收

- 日期单测覆盖 1 月 31 日、3 月 31 日、二月、闰年、跨年以及周视图前后导航，均只进入紧邻范围。
- 页面测试证明按钮与预留手势入口共用语义，页面上下文按规格保留或重置。
- placeholder 期间只显示目标日期网格和加载状态；失败停留并可重试/离开；快速连续导航不显示过期响应。
- 相关 Web 测试通过，且不新增服务端或数据库改动。

## Comments

- 本票只建立导航、查询和页面状态契约；触摸判定、DOM 接线与视觉反馈由票据 02、03 完成。
