# 03 — 隔离甘特条与排程交互

**What to build:** 确保日期格双击新建不会干扰已有工作计划的查看和排程操作。用户双击已有甘特条时只编辑该计划一次；日期表头、手柄和控件不会误建；移动、拉伸和悬停继续保持现有体验。

**Blocked by:** 01 — 双击日期格打开预填工作计划.

**Status:** ready-for-agent

- [ ] 双击已有甘特条只打开该工作计划的编辑抽屉一次，不创建新计划，也不出现抽屉开关闪烁。
- [ ] 日期数字及月份表头、甘特条、拖拽或拉伸区域、时间轴控件均不触发新建。
- [ ] 甘特条移动和左右两端拉伸不会误触发日期格双击新建。
- [ ] 现有甘特条单击编辑、整日移动、两端拉伸、悬停提示及列表行悬停同步保持正常。
- [ ] 上述排除区域与交互回归均有自动化测试覆盖。
