# 01 — 双击日期格打开预填工作计划

**What to build:** 让用户在周视图或月视图中双击时间轴日期网格背景，即可打开一次现有的新建工作计划抽屉。抽屉按鼠标所在日期列预填浏览器本地日期的 08:30–18:00，其余默认值、校验和保存流程与顶部“新建工作计划”入口一致。

**Blocked by:** None — can start immediately.

**Status:** done

- [x] 周视图和月视图中，双击日期网格背景只打开一次新建工作计划抽屉，并准确映射范围首日、中间日期和末日。
- [x] 开始、结束时间预填为目标浏览器本地日期的 08:30–18:00；过去、今天、未来和周末日期均可使用。
- [x] Automatic Status、Custom Field 默认值、Recurring Rule 默认值、校验、取消及保存行为与现有新建入口一致。
- [x] 单击日期网格背景无操作，双击打开抽屉前不创建或持久化工作计划。
- [x] 自适应列宽和月视图最小列宽下，日期映射均有自动化测试覆盖。
