# 02 — 空态日期网格与新建提示

**What to build:** 让没有可见工作计划的时间轴仍保留与当前周/月范围一致的日期网格，用户可以从空态直接双击新建；同时通过当前日期格高亮和“`双击新建工作计划`”提示，让这一入口可被发现。

**Blocked by:** 01 — 双击日期格打开预填工作计划.

**Status:** ready-for-agent

- [ ] 当前范围没有工作计划时，仍显示一天一列的日期网格，并可从任意可见日期双击打开正确预填的新建抽屉。
- [ ] 搜索、状态或 Custom Field 筛选导致无结果时，日期网格同样保留并可交互。
- [ ] 空态说明继续可见，但不遮挡日期定位、悬停反馈或双击事件。
- [ ] 鼠标位于可新建区域时，仅高亮当前日期格并显示“`双击新建工作计划`”；离开后清除反馈。
- [ ] 甘特条、日期表头及其他不可新建区域不显示新建高亮或提示。
- [ ] 周/月空态、筛选无结果及悬停生命周期均有自动化测试覆盖。
