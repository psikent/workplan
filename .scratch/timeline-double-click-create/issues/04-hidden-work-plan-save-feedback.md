# 04 — 不可见工作计划的保存反馈

**What to build:** 用户从日期格新建并保存工作计划后，继续停留在原时间范围和筛选上下文中；若新计划因用户修改日期或当前筛选条件而不可见，系统明确说明创建成功但当前未显示。

**Blocked by:** 01 — 双击日期格打开预填工作计划.

**Status:** ready-for-agent

- [ ] 保存后保持当前周/月视图、时间范围、搜索词、状态筛选和 Custom Field 筛选，不自动跳转或重置。
- [ ] 新工作计划符合当前范围和筛选条件时，显示正常创建成功反馈并按现有刷新流程出现。
- [ ] 用户把预填日期改到当前范围之外并保存时，提示工作计划已创建，但在当前时间范围或筛选条件下不可见。
- [ ] 新计划被搜索、状态或 Custom Field 筛选隐藏时，显示相同的明确不可见提示。
- [ ] 可见与不可见两类保存结果、范围保持和筛选保持均有自动化测试覆盖。
