# Spec: “工作内容”作为甘特条属性可选项

> Status: **已完成** — 规格已定稿（/grill-with-docs 共识，2026-08-31）；票据 01–02 已实现，TDD 落地，web 259 / server 132 测试与全仓类型检查通过（2026-08-31）。`scripts/release.test.mjs` 在 Git Bash/Windows 下存在既有环境性失败（MSYS 路径转换），与本次无关，干净 HEAD 上同样复现。

## Goal

在计划页面的“甘特条属性”设置面板中，新增内置属性**工作内容**（Work Plan 的 `title`）作为可勾选项：勾选后，甘特条上显示该计划的工作内容（超长截断）。

## Terms

见 `CONTEXT.md`：**Work Plan**、**Work Content（工作内容）**、**Custom Field**。

本文“工作内容”专指 Work Plan 的 `title` 字段（必填、≤200 字的单行标题），即列表固定首列、新建/编辑抽屉与导出中标注“工作内容”的同一字段；不是长文本字段“说明”（`description`）。

## Background facts

- 甘特条属性面板（`WorkPlansPage.tsx` 的 `GanttPropertySettings`）有两个独立分区：**甘特条属性**（条上标签）与**甘特条浮动提示**（hover 明细），各自维护勾选与排序。
- 可选项列表 = 内置属性“状态” + 服务端下发的 Custom Field（`GET /custom-fields`，如 工作负责人、风险等级 等）。“工作内容”目前不在任何分区中。
- 甘特条标签由 `GanttTimeline.tsx` 的 `formatGanttLabel` 渲染：按勾选顺序把各属性值用 `" · "` 连接，空值（`—`）丢弃；标签是 SVG 文本、居中显示，**当前无任何截断**。
- 浮动提示由 `formatGanttTooltip` 渲染：**第一行固定显示 `plan.title`（全文）**，其后为日期区间与勾选的属性明细行。
- 两分区的勾选状态分别持久化在 localStorage `workplan:gantt-properties:v1` / `workplan:gantt-tooltip:v1`，加载时按合法 id 白名单校验，未知 id 丢弃、坏数据回退为空。

## Decisions（/grilling 共识，2026-08-31）

1. **D1 字段映射**：“工作内容” = `title`，作为第二个内置属性（徽标“内置属性”，与“状态”同级）。
2. **D2 仅甘特条属性面板提供**：浮动提示面板**不**新增“工作内容”——浮动提示固定标题行已全文显示工作内容，再列为可选项只会重复。
3. **D3 列表位置**：置于甘特条属性列表**顶部**（“状态”上方），浮动提示分区完全不变。
4. **D4 条上截断**：工作内容超过 20 字时，甘特条上显示前 20 字 + `…`；其它属性值不截断；浮动提示仍显示全文（固定标题行）。

## Requirements

### R1 设置面板

- “甘特条属性”分区新增可选项“工作内容”：徽标“内置属性”，位于列表第一项（“状态”之上）。
- 默认不勾选；“清空”、上移/下移排序、勾选持久化等既有交互对它同样适用。
- “甘特条浮动提示”分区不新增任何选项，行为与现状完全一致。

### R2 持久化

- 勾选状态随现有 `workplan:gantt-properties:v1` 保存，新增合法 id `title`。
- 旧数据兼容：已存在的存储数据（不含 `title`）加载行为不变；含 `title` 的数据须被接受，不再按未知 id 丢弃。
- 浮动提示的存储 key 与数据格式不变。

### R3 甘特条标签渲染

- 勾选“工作内容”后，甘特条标签按勾选顺序包含其值：值取 `plan.title`。
- 截断规则（仅条上标签）：字数 > 20 时显示前 20 字 + `…`；≤ 20 字原样显示。截断按单个属性值进行，不影响同标签其它属性值。
- `title` 必填，不出现 `—` 占位丢弃的情况；与其它属性的 `" · "` 连接、空值丢弃、标签居中等既有逻辑不变。

### R4 浮动提示

- 浮动提示渲染不因本需求改动：固定标题行继续全文显示工作内容，明细行、日期区间、持续天数等保持现状。

## Testing requirements

- 页面测试（`WorkPlansPage.test.tsx`）：
  - 甘特条属性分区第一项为“工作内容”，徽标为“内置属性”；
  - 勾选“工作内容”后写入 localStorage、重载后保持；“清空”可取消勾选；
  - 浮动提示分区不含“工作内容”选项。
- 组件测试（`GanttTimeline.test.tsx`）：
  - `formatGanttLabel`：≤20 字原样；>20 字截断为前 20 字 + `…`；与其它属性按勾选顺序 `" · "` 连接，其它属性值不被截断逻辑影响。
- 渲染测试（`GanttTimeline.render.test.tsx`）：勾选后甘特条上实际显示截断后的工作内容。
- 既有甘特/面板测试全部保持通过。

## Acceptance criteria

1. 打开“甘特条属性”面板，“工作内容”以“内置属性”徽标出现在列表第一项；浮动提示分区无此选项。
2. 勾选后甘特条标签显示工作内容，>20 字时为前 20 字 + `…`，≤20 字全文。
3. 同时勾选多个属性时，标签按勾选顺序 `" · "` 连接，非工作内容属性值不受截断影响。
4. 勾选状态刷新页面后保持；“清空”后恢复默认（不勾选）。
5. 浮动提示内容与现状完全一致，固定标题行全文显示工作内容。
6. 旧版 localStorage 数据加载无回归。
7. 无服务端改动；不新增 API、不改动导出与列表列。
8. Web 类型检查与相关测试全部通过。

## Out of scope

- “甘特条浮动提示”分区新增“工作内容”选项（已否决：固定标题行已显示全文，重复）。
- “说明”（`description`）字段成为可选项。
- 截断阈值可配置、按像素/CSS 截断。
- 计划列表列、导出模板的任何改动（二者已有“工作内容”）。
- 服务端、权限、Custom Field 定义的任何改动。
