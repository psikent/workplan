# 03 — 前端:抽屉底部「更多信息」折叠区
Type: task
Status: ready-for-agent
Blocked by: 01
Spec: ../spec.md
Scope: apps/web/src/components/WorkPlanDrawer.tsx

## 背景

规格 R4/R5。抽屉为查看/编辑/新建三合一;自定义字段在单个 `form-section` 平铺,排序=必填优先再 sortOrder(`WorkPlanDrawer.tsx:228-230`);`owner` 字段特例包冲突提示+派生只读「工作负责人账号」(:231-239、:316-325);保存错误统一顶部 `form-error`(:333),必填校验失败来自服务端,错误文本形如 `自定义字段"X"为必填项`(含字段 label)。票据 01 落地后契约携带 `collapsed`。

## 改动清单

1. 字段分流:未折叠字段留在「自定义字段」分区(排序规则不变);折叠字段划入底部新折叠区,区内同排序规则、同控件渲染(CustomFieldControl),可查看/编辑。
2. 折叠区:位于「自定义字段」分区之后、底部按钮之前;标题「更多信息 (N)」可点击展开/收起,带 `aria-expanded`;默认收起,每次打开抽屉重置;无折叠字段(N=0)不渲染;全部折叠时主分区不渲染空壳。
3. owner 特例:`owner` 折叠时冲突提示区与「工作负责人账号」派生只读字段整体随入折叠区。
4. 校验兜底:保存失败(error 置位)且折叠区收起时自动展开;错误文本匹配某折叠字段 label 时滚动定位到该字段控件。
5. 三种模式(查看/编辑/新建)行为一致。

## 验收

- 对应规格 R4/R5 与验收标准 2:隔离实例手工验证——折叠字段入「更多信息」、展开可编辑;默认收起、重开重置;owner 随折叠;必填折叠字段留空保存→自动展开并定位;未折叠字段行为与现状一致。
- `corepack pnpm --filter @workplan/web typecheck` 全绿(本组件如无既有测试覆盖,不强制新增单测,以隔离实例手工验收为准)。
