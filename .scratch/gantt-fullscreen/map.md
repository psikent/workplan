# 工作计划甘特图页面内全屏决策地图

Status: implemented
Type: map

## Destination

把工作计划页的甘特面板扩展为一个可退出、可访问、可回归测试的页面内全屏模式：保留工作计划排期所需的列表和时间轴交互，隐藏页面级干扰元素，不改变查询和业务数据语义。

## Notes

- 领域：Work Planning；沿用 **Work Plan（工作计划）**、**Work Content（工作内容）** 和 **Gantt Fullscreen Mode（甘特图全屏模式）**。
- 附件截图只提供按钮位置/视觉参考；不把截图中的现有按钮文字推导为额外需求。
- 本地图只做规格和票据；功能实现、提交和发布须在用户批准规格后另行授权。
- 环境事实已由只读代码勘察确认：`.planner-panel` 包含甘特工具栏、列表/分页与时间轴；`WorkPlanDrawer` 是其兄弟 fixed 抽屉；仓库没有原生全屏机制。

## Decisions so far

- [页面内全屏与保留面板交互](./spec.md) — 保留浏览器栏、列表、工具栏、周/月视图和分页；隐藏应用侧栏及页面级操作。
- [抽屉、查询条件与浮层](./spec.md) — 全屏可打开详情/编辑抽屉；查询条件保持，已展开浮层进入时关闭。
- [临时生命周期与滚动保持](./spec.md) — 刷新/离开页面恢复普通布局，全屏切换保留列表与时间轴滚动位置。

## Not yet specified

- 无。2026-09-06 用户批准后按 01–03 票据完成实现，测试/typecheck/build/浏览器验收与 code-reviewer 复核全部通过（详见各票据 Comments）。窄屏工具栏换行适配与查询错误横幅豁免两项实施偏差记录在票据 02。

## Out of scope

- 浏览器原生全屏、API/数据库/权限改动、全屏偏好持久化，以及甘特已有业务交互的重设计。
