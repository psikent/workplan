# Spec: 工作计划甘特图页面内全屏模式

> Status: **待批准** — 需求访谈（`grill-with-docs` 共识 Q1–Q8，2026-09-06；用户确认共享理解），当前只形成规格与票据，尚未修改业务代码。

## Goal

在工作计划页面的甘特面板工具栏中增加全屏按钮，让用户在保留浏览器标签栏和地址栏的前提下，把甘特面板扩展到整个应用窗口。全屏聚焦工作计划的时间安排，同时保留工作内容列表、时间轴工具栏、周/月视图、分页和现有甘特交互。

## Source boundary

附件截图只作为按钮位置和紧凑图标样式的视觉参考：按钮位于甘特图中央日期标题的右侧。截图中的“搜索工作计划”“筛选”“排序”“导出 XLS”等既有文字不构成额外指令，本规格不改变这些功能的业务语义。

## Terms

见 `CONTEXT.md`：**Work Plan（工作计划）**、**Work Content（工作内容）**、**Gantt Fullscreen Mode（甘特图全屏模式）**。

本文“甘特面板”指 `WorkPlansPage` 中的 `.planner-panel`，包括顶部时间轴工具栏、左侧工作内容列表及分页、右侧 Frappe Gantt 时间轴。本文“页面级元素”指应用侧栏、工作计划页标题/说明、模板与导出操作、搜索/筛选/排序入口及其展开面板、新建操作和其他围绕甘特面板的页面布局。

## Background facts

- `apps/web/src/pages/WorkPlansPage.tsx` 当前将页面级元素和 `.planner-panel` 放在同一页；面板的 `.table-toolbar` 中已有上一范围、今天、下一范围、中央 `rangeTitle`、列设置、周/月视图和甘特条属性设置。
- `.planner-panel` 目前是三列布局：工作内容列表、可拖动分隔线、甘特时间轴；左表分页位于 `planner-table` 底部。`collapsed` 只控制左侧列表，不能被全屏状态覆盖。
- `apps/web/src/components/AppShell.tsx` 在 `app-shell` 中渲染应用侧栏和 `app-main`；离线横幅位于 `app-main`、工作计划页面之外。全屏需要让应用壳层为甘特面板提供完整可用高度。
- `WorkPlanDrawer` 是 `.planner-panel` 的兄弟节点，以 fixed drawer/backdrop 形式渲染，现有抽屉可查看、编辑和保存工作计划；全屏实现必须让它继续位于甘特面板之上。
- 工作计划查询的搜索、状态/自定义字段筛选、排期排序、时间范围和游标分页由 `WorkPlansPage` 管理；本需求不增加 API、不改变服务端查询或分页数据。
- 甘特时间轴已有列表与时间轴的纵向同步、日期范围切换、周/月视图和滚动容器；全屏切换会改变尺寸，不能因此重置用户当前浏览位置。
- 当前代码没有 `requestFullscreen`、`exitFullscreen` 或其他浏览器原生全屏机制；本需求采用页面内的临时展示状态。

## Decisions（`grill-with-docs` 共识，2026-09-06）

| # | 决策 | 结论 |
| --- | --- | --- |
| Q1 | 全屏层级 | 页面内全屏，保留浏览器标签栏和地址栏 |
| Q2 | 面板内容 | 保留工作内容列表；保留日期切换、周/月视图、列/甘特设置和分页 |
| Q3 | 页面范围 | 隐藏应用侧栏、页面标题/说明、模板/导出、新建、搜索/筛选/排序等页面级元素；甘特面板铺满应用窗口 |
| Q4 | 抽屉 | 全屏中允许打开详情/编辑抽屉，关闭抽屉后仍回到全屏 |
| Q5 | 查询状态 | 搜索、筛选和排序条件继续作用于当前甘特数据；进入时关闭已打开的设置浮层，退出后控件和条件仍保留 |
| Q6 | 生命周期 | 全屏只在当前页面会话有效；刷新或离开工作计划页后恢复普通布局 |
| Q7 | 按钮 | 中央日期标题右侧使用紧凑图标按钮，进入/退出时切换图标、`aria-label` 和悬停提示 |
| Q8 | 滚动位置 | 进入/退出时保留左侧列表纵向滚动和时间轴横向滚动 |

## Requirements

### R1 — 进入、退出与可访问性

- 在甘特面板中央日期标题的右侧增加一个图标按钮；它不移动日期标题的视觉中心，也不挤压现有左右工具栏。
- 普通状态按钮的 `aria-label`/`title` 为“进入全屏”，全屏状态为“退出全屏”；图标须能区分两种状态。按钮可由键盘聚焦并有现有焦点样式。
- 点击按钮切换甘特图全屏模式；使用 `Esc` 在没有打开抽屉时退出全屏。全屏不调用浏览器原生 Fullscreen API，不改变地址栏、标签栏或路由 URL。
- 进入或退出不得触发工作计划保存、查询重置、时间范围跳转或其他业务写入。

### R2 — 全屏布局

- 全屏时应用侧栏、离线/页面级布局占位、工作计划标题与说明、模板/导出、新建、搜索/筛选/排序入口及展开面板均不占用可见空间；甘特面板扩展到应用窗口可用区域。
- 甘特面板仍显示：左侧工作内容列表（沿用进入时的展开/折叠状态）、列表分页、上一范围/今天/下一范围、中央日期标题、全屏退出按钮、列设置、周/月切换、甘特条属性设置及右侧时间轴。
- 全屏面板在桌面和窄屏都不能产生页面级横向滚动；窄屏继续遵循既有列表/时间轴分栏、抽屉宽度和控件触控尺寸规则。
- 退出后恢复普通页面布局，页面级元素回到原来的位置；全屏期间已有的列表折叠、列表宽度、视图和日期锚点不被覆盖或写入新的持久化偏好。

### R3 — 查询、浮层与抽屉

- 进入全屏前已应用的搜索词、状态/自定义字段筛选、排期排序、时间范围、游标页和甘特显示偏好继续有效，甘特展示的工作计划集合不因全屏改变。
- 进入全屏时关闭已展开的导出、导入、筛选、排序、列表列设置和甘特条属性浮层；退出全屏不会自动重新打开这些浮层，但其选择值保持不变。
- 全屏中点击甘特条、提醒或列表工作内容，继续使用现有选择逻辑打开 `WorkPlanDrawer`；抽屉和遮罩作为临时模态层覆盖甘特面板，关闭后仍处于全屏。抽屉打开时按 `Esc` 先关闭抽屉；无抽屉时按 `Esc` 退出全屏。
- 只读账户与可写账户都能进入和退出全屏；全屏不放宽现有查看、排程拖动或编辑权限。

### R4 — 尺寸变化与滚动保持

- 全屏切换引起 Gantt 容器重排时，恢复切换前的列表纵向 `scrollTop` 与时间轴横向 `scrollLeft`；现有列表/时间轴纵向同步仍以浏览器最终钳制值为准。
- 切换视图、日期范围、折叠列表、拖动分隔线或打开抽屉后的既有滚动语义保持不变；仅全屏切换不得把滚动位置跳到起点。

### R5 — 数据与范围

- 不新增或修改服务端接口、数据库字段、Work Plan、Work Plan Time Range、Schedule Order 或权限语义。
- 不改变导出内容、列表列配置、甘特条属性、提醒、排程拖动/拉伸和双击日期格新建行为。
- 不保存全屏偏好到 `localStorage`；离开路由或刷新后初始状态始终为普通布局。

## Testing requirements

- `WorkPlansPage` 页面测试覆盖：按钮位置语义与动态 `aria-label`、点击进入/退出、`Esc` 退出、刷新/重新挂载初始为普通布局、页面级元素在全屏状态隐藏、面板内列表和工具栏仍可见。
- 页面测试覆盖：进入全屏前打开的浮层被关闭但搜索/筛选/排序值保持；全屏中点击工作计划仍打开抽屉，抽屉 `Esc` 优先关闭且第二次 `Esc` 退出全屏。
- 组件/渲染测试覆盖：全屏 class/属性变化不会改变传给 `GanttTimeline` 的 plans、range、view、display properties 或 read-only 状态；列表折叠状态和现有滚动同步回归保持。
- CSS/浏览器验收覆盖浅色、深色、桌面和约 390px 窄屏：面板填满应用窗口、中央日期标题与按钮位置稳定、无页面级滚动条、列表展开/折叠均可操作、抽屉覆盖层可关闭、全屏退出后布局恢复。
- 实施完成后按仓库约定运行 Web 专项测试、Web typecheck、Web build；非平凡代码变更在自提交前先经过 `code-reviewer` 审查并修复 P0/P1。

## Acceptance criteria

1. 在中央日期标题右侧看到紧凑全屏图标按钮，按钮有准确的进入/退出无障碍名称和提示。
2. 点击后应用侧栏、页面标题/说明、搜索/筛选/排序、新建、模板/导出等页面级元素隐藏，甘特面板填满应用窗口。
3. 工作内容列表、列表分页、日期导航、中央日期、周/月视图、列/甘特设置和时间轴仍可操作；列表进入时的展开/折叠状态保持。
4. 当前搜索、筛选、排序、时间范围、分页和甘特显示结果不因全屏改变；已展开浮层关闭，选择值保留。
5. 全屏中打开并关闭详情/编辑抽屉的行为正常；抽屉打开时 `Esc` 关闭抽屉，无抽屉时 `Esc` 退出全屏。
6. 全屏切换保留列表纵向和时间轴横向滚动位置，桌面和窄屏无额外页面级滚动。
7. 刷新或离开工作计划页后恢复普通布局；不使用浏览器原生全屏，不新增 API 或数据库改动。
8. 相关测试、typecheck、build 和浏览器验收通过。

## Out of scope

- 浏览器原生全屏、隐藏操作系统菜单栏、标签栏或地址栏。
- 只显示右侧时间条而隐藏工作内容列表。
- 在全屏状态中重新设计甘特工具栏、列表列、甘特条属性、导出、筛选、排序或抽屉字段。
- 保存或跨路由恢复全屏偏好。
- 修改 Work Plan 数据、查询接口、数据库、权限和生产环境配置。
