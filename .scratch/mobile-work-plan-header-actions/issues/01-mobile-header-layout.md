# 01 — 手机端页头同行布局

Type: task
Status: resolved
Spec: ../spec.md
Scope: `apps/web/src/styles.css`，必要时仅调整 `apps/web/src/pages/WorkPlansPage.tsx` 的展示标记

## 目标

根据 spec D1–D3，在 `<=720px` 的手机端将 WorkPlansPage 的“工作计划”标题、模板选择框和“导出 XLS”按钮布局为一行：标题在左，现有操作组在右；不改变任何操作逻辑。

## 改动要求

1. 仅覆盖手机端现有媒体查询，桌面端和非手机规则不变。
2. 取消当前手机端页头的纵向堆叠效果，保持标题左侧、操作组右侧。
3. 让操作组在最小 320px 页面宽度内不换行；空间不足时允许模板选择框收缩/截断，导出按钮保持稳定的可操作尺寸。
4. 保留现有模板选择框、导出弹层包裹元素、按钮文案、图标、ARIA 属性和事件逻辑。
5. 不移动筛选栏中的控件；不引入页级横向滚动。

## 验收清单

- [x] 390px 视口的同行布局规则已实现，操作组右对齐。
- [x] 360px 视口的无换行、模板名称收缩和导出按钮稳定宽度规则已实现。
- [x] 320px 视口的无换行、无整页横向滚动和导出按钮稳定宽度规则已实现。
- [x] 桌面端未增加覆盖规则，保留现有页头布局。
- [x] `WorkPlansPage` 现有模板、导出、权限测试保持通过。
