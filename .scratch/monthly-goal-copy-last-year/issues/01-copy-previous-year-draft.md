# 01 — 复制去年年度草稿
Type: task
Status: resolved
Blocked by: none

## 背景

年度快速编辑已支持按名称集中维护一个年份的 1–12 月活跃状态。本票在工具栏增加“复制去年”，将上一年未归档名称—月份矩阵安全映射为当前年度草稿，不改变既有批量保存接口。

## 改动清单

1. 在“新增一行”左侧增加“复制去年”按钮、来源年份可访问名称、请求中状态和年份下界禁用。
2. 从现有年度 GET 读取上一年数据，过滤归档实例并按既有规则聚合。
3. 从当前年度服务器快照重建目标行：同名行复用目标实例元数据，来源独有行作为新行，目标年独有行清空月份后追加。
4. 脏草稿先确认；取消不查询，确认后不基于已修改草稿叠加。
5. 增加成功、结构一致、无来源和读取失败反馈，任何失败均不改变当前草稿。
6. 保持现有 baseline、提交载荷、保存、409 冲突、关闭和切年行为。
7. 将复制与新增按钮纳入同一响应式操作区。
8. 补齐组件级自动化测试。

## 验收

- 规格 R1–R4 全部实现。
- 不新增后端接口、契约或数据库迁移。
- 复制后的提交载荷只表达目标年度名称和月份状态。
- 组件专项测试、Web 类型检查和 Web 构建通过。
