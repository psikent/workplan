# 单选字段排序按选项管理顺序，而非标签文字

工作计划按单选（single_select）自定义字段排序时，依据选项的管理顺序（`custom_field_options.sort_order`，由管理员维护），不按选项标签的文字序（自然排序）。选项顺序承载业务语义——如风险等级 可接受/低/中/高 的重要性序无法从标签码点序恢复（码点序为 中 < 低 < 高）；标签带编号（1.值班/2.休假…）时两种序恰好一致，掩盖了差异，2026-09-07 的「备注」排序疑问即源于此。

## Considered Options

- **按标签自然序排序**（被拒）：对编号标签碰巧成立，但语义顺序（高/中/低）会排错，且新增选项无法插入到语义正确的位置（永远按文字落位）。
- **按管理顺序排序**（采纳）：管理员一次定序，处处一致；代价是需要选项重排能力（见 `.scratch/custom-field-option-reorder/`）。

## Consequences

- 归档选项保留其顺序位：持有历史归档选项值的计划，仍按该选项的 `sort_order` 排序（排序 JOIN 不滤归档）。
- 选项顺序不随环境配置包迁移：包内选项仅携带 value/label，同步导入不比对顺序（见 spec 已知限制）。
